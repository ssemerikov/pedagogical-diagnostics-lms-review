# Data dictionary

Everything under `data/` is exported from the review's working files through an explicit whitelist of files and
fields. Abstracts, full texts and Scopus fields other than identifiers, titles and years are left out (see
[README](../README.md#what-is-not-here)). JSON Lines files (`.jsonl`) hold one JSON object per line. Where a file
holds several lines for the same id, the last line is the one that counts.

## Arms and identifiers

| Arm | Records | Identifier |
|---|---|---|
| `O1` | the original OUCI search (January 2026), decisions as made then | `OUCI-NNN` (record number in `data/original/supplementary_screening.csv`) |
| `O1-chaining` | the one study added to the original review by citation chaining | its citation key |
| `N` | the 31 originally unretrieved records (excluded in January 2026 for lack of an open-access full text), sought again in the update | `OUCI-NNN` |
| `S` | Scopus (update) | Scopus EID, `2-s2.0-…` |
| `O2` | OUCI re-run (update) | `OUCI2-` + the OUCI work identifier |

The ten studies included in the original review are identified by their citation keys in the article
(`data/reextract/in.jsonl`), for example `kolgatin2020systematicity`.

## `data/screening_master.csv`: one row per record per arm

Generated by `make counts` (`pipeline/make_counts.py`).

| Column | Values |
|---|---|
| `arm` | `O1`, `O1-chaining`, `N`, `S`, `O2` |
| `id`, `doi` | identifier (above) and DOI, lower case |
| `stage` | furthest stage reached: `dedup`, `ta` (title and abstract), `retrieval`, `full_text` |
| `ta`, `ta_code` | title/abstract verdict after the audit (`pass`, `maybe`, `exclude`) and its code |
| `retrieval` | `retrieved`, `not_retrieved`, or empty when the record did not reach retrieval |
| `route` | how a full text of an update record was obtained: `oa_auto` (automated open-access retrieval), `manual_user` (saved by a member of the review team, through open access or library access), `author` (from the authors) |
| `final` | `included`, `excluded` (at full text), `excluded_ta`, `not_retrieved`, `not_retrieved_usable` (the only copy obtained was unusable), `duplicate_of_O1`, `duplicate_of_S`; `pending_*` while a decision is open |
| `reason` | for `O1`, the reason recorded in January 2026; for the update, the exclusion code (below) |
| `decided_by` | who made the decision: the first author (original review, after a first pass by Gemini 3.0); `update pipeline (two language models, no author verification)`; or the duplicate-matching rule |

## Codes

Defined in [`prompts/01_title_abstract_first_pass.md`](../prompts/01_title_abstract_first_pass.md),
[`prompts/03_fulltext_assessment.md`](../prompts/03_fulltext_assessment.md) and
[`prompts/03b_fulltext_decision_rules.md`](../prompts/03b_fulltext_decision_rules.md).

| Code | Meaning |
|---|---|
| `I1`-`I4` | inclusion criteria (empirical data linking LMS-measurable indicators, or indicators from learning-activity products, with learning-action success or with personality-related constructs) |
| `E1`-`E7` | exclusion criteria as worded in the article; `E5` is never applied |
| `E7` (update) | amended: full text not obtainable by the review team (open access, library access or author request). The original January 2026 decisions keep the original wording, "full text not available in open access" |
| `OFF` | off-domain (title/abstract only) |
| `NONEMP` | not a primary empirical study |
| `NOIND` | no LMS- or online-environment-measurable indicator at all (title/abstract only) |
| `NOREL` | an indicator exists but is never related to success or a construct, or all data are self-report (full text) |

## Files

| Path | Content | Produced by |
|---|---|---|
| `data/original/supplementary_screening.csv` | the 118 records of the original OUCI search with the January 2026 decision and reason | original review |
| `data/scopus/search_meta.json` | Scopus query, field, limits, run time and number of results | `pipeline/scopus_harvest.py` |
| `data/scopus/records.jsonl` | the 596 Scopus records: `eid`, `doi`, `title`, `year` only | `pipeline/scopus_harvest.py` |
| `data/scopus/openalex.jsonl`, `data/{ouci,noaa,reextract}/openalex.jsonl` | OpenAlex metadata per record (match type, OpenAlex id, title, year, language, type, open-access status and locations); abstracts removed | OpenAlex enrichment |
| `data/scopus/screening_setup.json` | Scopus records already in the original review (matched by DOI) and the calibration ids (known included studies seeded blind) | orchestrator |
| `data/scopus/ta_batches/{A,B,C}_NNN.jsonl` | first-pass title/abstract verdicts: `verdict`, `code`, `reason`, `screener` | Claude Sonnet 5.5 |
| `data/scopus/ta_verdicts.jsonl` | shards A and B of the above, merged; the adjudicator drew its title/abstract sample from these and from shard C (the OUCI re-run) | orchestrator |
| `data/scopus/ta_audit/excl*_NNN.jsonl` | audit of the exclusions: `audit` (`uphold`/`overturn`), `new_verdict`, `code`, `reason` | Claude Opus 5.5 |
| `data/scopus/ta_audit/maybe*_NNN.jsonl` | priority given to each `maybe` for full-text assessment; a `maybe` is never excluded at title/abstract | Claude Opus 5.5 |
| `data/ouci/run_meta.json` | OUCI re-run: query field, scope evidence, run time, number of results | orchestrator |
| `data/ouci/ouci_rerun.jsonl` | the 184 records of the OUCI re-run with result page and rank | orchestrator |
| `data/ouci/new_records.jsonl` | the re-run records not in the original 118 | orchestrator |
| `data/ouci/screening_setup.json` | re-run records that duplicate the original review or Scopus | orchestrator |
| `data/noaa/in.jsonl` | the 31 originally unretrieved records sought again | orchestrator |
| `data/reextract/in.jsonl` | the ten originally included studies, re-extracted | orchestrator |
| `data/*/retrieval_log.jsonl` | automated retrieval: per record `result`, `route` and every `attempts` entry (`url`, `outcome`, `date`) | retrieval script |
| `data/fulltext_routes.jsonl` | how each full text was obtained (`id`, `route`, `logged_on` date). `invalid` marks a wrong or unusable file, superseded by a later line | `pipeline/ingest_fulltexts.py` |
| `data/ft/assess/<id>.json` | full-text eligibility decision, criteria met, exclusion code, reason, data extraction with verbatim evidence quotes (each at most 300 characters); for the ten original studies also `table2_current` | Claude Opus 5.5 |
| `data/ft/adjudicate/<id>.json` | the adjudicator's own decision (field `independent_decision`), agreement, final decision and code, reason, check of every extracted number (`extraction_check`); for the ten original studies the sensitivity re-reading (`sensitivity`) | Claude Fable 5.2 |
| `data/ft/adjudicate_ta_sample.jsonl` | re-check of a 10% random sample of the title/abstract exclusions other than `OFF` | Claude Fable 5.2 |
| `data/ft/noaa_abstract_triage.jsonl` | abstract-only triage of the originally unretrieved records still without a full text | Claude Fable 5.2 |
| `data/ft/effect_size_classification.jsonl` | for each included study, whether an extracted statistic is an indicator-outcome effect size, under the rule written in `pipeline/make_counts.py` | orchestrator |
| `data/prisma_counts.json`, `data/counts.tex` | every count used in the article; `counts.tex` holds the LaTeX macros | `make counts` |
| `data/supplement/S1`-`S4` | the article's supplementary material, as submitted | see README |

## Labels inside the data

Model outputs are reproduced as written. They contain labels from the review's working process:

| Label | Meaning |
|---|---|
| `WP02a` | Scopus harvest |
| `WP02b first pass`, `WP02b audit` | title/abstract screening and its audit ([prompts 01 and 02](../prompts/README.md)) |
| `WP02d` | full-text assessment and extraction ([prompt 03](../prompts/03_fulltext_assessment.md)) |
| `WP05b` | adjudication by a second reading ([prompt 04](../prompts/04_adjudication.md)). Part A: every full-text decision; Part B: the title/abstract sample; Part C: re-reading of the ten originally included studies under the update's rules (their original decisions are not changed); Part D: abstract triage |
| `brief_2b`, `rule_notes` | the files now published as [prompt 01](../prompts/01_title_abstract_first_pass.md) and [prompt 05](../prompts/05_adjudicator_notes_on_rules.md) |
| `Rule I` | the E4/NOREL tie-break ([prompt 03b](../prompts/03b_fulltext_decision_rules.md); prompt 05, section 11) |
| `D2` | the update's screening and eligibility decisions are made by two language models, without author verification |
| `D8` | the amendment of exclusion criterion E7 for the update (above); the January 2026 decisions are reported as made |
| `D12` | studies with mixed or borderline samples are included under the shared reading of E3 ("only clearly non-HE/VET samples"); a strict reading would exclude them (see the comment in `pipeline/make_counts.py`) |
| `WP07a`, `WP11 F025` | stages of the revision of the article that use a count (comments in `pipeline/make_counts.py`) |
| `R7.3`, `R7.4` | points 3 and 4 of a reviewer's report on the article (comments in the pipeline and in prompt 04) |
| `audit_notes` | the title/abstract auditor's working notes, not published |
| orchestrator | the coordinating model of the review update (Claude Opus 5.5), which ran the scripts |
